# 今月あといくら？

使った金額だけを入れると、「今月あといくら使えるか」と「1日あたりの目安」が分かる、ブラウザだけで動くツールです。

## 使い方

1. `あといくら.html`をブラウザで開く（インストール不要、インターネット接続も不要）
2. 「今月の予算（自由に使えるお金）」を入れる
3. お金を使ったら、金額だけを入れて「使った」を押す（Enterでも追加できる。+100 / +500 / +1,000のボタンで足し算もできる）
4. 「今月あと」「1日あたり」「今日使った」がその場で更新される

## 計算のルール

- 今月あと ＝ 予算 − 今月使った合計
- 1日あたり ＝ 今月あと ÷ 残り日数（今日を含む）。今月あとが0以下なら¥0
- 残り日数 ＝ 今月の日数 − 今日の日付 + 1
- 予算を超えたら、残りが赤いマイナス表示になる

## データについて

- 記録はこのブラウザ内（localStorage）にのみ保存されます。外部には送信しません
- 予算は翌月に引き継がれ、記録は月ごとに分かれます（前月の記録は表示されません）
- ブラウザのサイトデータを消すと記録も消えます

## ファイル

- `あといくら.html` : アプリ本体（1ファイルで完結、外部ライブラリなし。JavaScriptは約120行）
