# 今月あといくら？

使った金額だけを入れると、「今月あといくら使えるか」と「1日あたりの目安」が分かる、ブラウザで動くツールです。スマホのアプリとしても使えます。

## 使い方

1. ブラウザで開く（インストール不要）: https://dicekakumei.github.io/atoikura/ （手元の`あといくら.html`を直接開いても動く）
2. 「今月の予算（自由に使えるお金）」を入れる
3. お金を使ったら、金額だけを入れて「使った」を押す（Enterでも追加できる。+100 / +500 / +1,000のボタンで足し算もできる）
4. 「今月あと」「1日あたり」「今日使った」がその場で更新される。記録は自動で保存され、開き直しても残る

## スマホで使う

### Androidアプリ（APK）
- [Releases](https://github.com/DiceKakumei/atoikura/releases)から`atoikura.apk`をダウンロードして開く
- 「提供元不明のアプリ」のインストール許可が必要（個人が配布しているため。Google Playには出していない）
- 中身はブラウザ版と同じ（Capacitorで包んだもの）。ビルドは`.github/workflows/build-apk.yml`（GitHub Actions）で自動化している
- 動作確認：Androidエミュレーター（Pixel 6、Android 14）で、インストール・起動・入力・アプリを閉じて開き直してもデータが残ることを確認済み（`.github/workflows/emulator-demo.yml`、`demo/`）。実機での確認は未実施

### ホーム画面に追加（AndroidでもiPhoneでも）
- ブラウザで上のURLを開き、メニューの「ホーム画面に追加」（iPhoneはSafariの共有ボタン→「ホーム画面に追加」）
- アイコンから全画面で開ける。一度開けば、圏外でも使える

## 計算のルール

- 今月あと ＝ 予算 − 今月使った合計
- 1日あたり ＝ 今月あと ÷ 残り日数（今日を含む）。今月あとが0以下なら¥0
- 残り日数 ＝ 今月の日数 − 今日の日付 + 1
- 予算を超えたら、残りが赤いマイナス表示になる

## データについて

- 記録はこの端末のブラウザ（またはアプリ）内（localStorage）にのみ保存されます。外部には送信しません
- 予算は翌月に引き継がれ、記録は月ごとに分かれます（前月の記録は表示されません）
- ブラウザのサイトデータを消す、またはアプリを削除すると記録も消えます。ブラウザ版とAPK版でデータは共有されません

## ファイル

- `あといくら.html`（= `index.html`）: アプリ本体（外部ライブラリなし。JavaScriptは約120行）
- `manifest.webmanifest` / `sw.js` / `icons/`: ホーム画面に追加して使うための設定・オフライン用・アイコン
- `android-res/`: Androidアプリ用のアイコン
- `.github/workflows/build-apk.yml`: APKのビルド設定
